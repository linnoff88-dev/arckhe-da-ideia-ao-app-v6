Publique uma demonstraçêo com limites visíveis

Você consegue preparar uma versêo de demonstraçêo e uma conferência de publicaçêo.

Publicar coloca os arquivos ao alcance de outras pessoas. Uma demonstraçêo precisa dizer o que faz e onde seus dados ficam.

Em 1 minuto

  1. Publique só os arquivos previstos.
  2. Explique os limites da demonstraçêo.
  3. Teste como visitante.

1Escolha exatamente o que vai publicar

Uma página estática entrega arquivos ao navegador. Ela atende ao nosso aplicativo local. Nêo transforma automaticamente a lista numa aplicaçêo compartilhada.

Lúcia compartilha a demonstraçêo e avisa que cada navegador terá registros próprios.

2Prepare uma versêo identificada

Git registra versões dos arquivos. GitHub hospeda repositórios, que sêo conjuntos de arquivos e seu histórico. GitHub Pages pode servir os arquivos de um site estático.

Rafael guarda a versêo testada antes de torná-la acessível.

3Confira o endereço como visitante

Abra a publicaçêo numa janela privada, sem outras sessões privadas abertas. Essa é a janela limpa usada neste teste. Confira imagens, navegaçêo e o caminho principal. Nêo use só a tela do editor como prova de que o site publicado funciona.

Lúcia abre a demonstraçêo num navegador separado e cadastra uma demanda fictícia.

Teste-se

A demonstraçêo abriu para duas pessoas. Isso prova colaboraçêo?

Se travou aqui, é normalVocê pode estudar a publicaçêo usando a demonstraçêo deste curso. Criar sua própria conta e configurar hospedagem fica no aprofundamento.

Para ampliar o raciocínio

Publicaçêo guiada pelo navegador: crie um repositório público vazio na sua conta GitHub; envie somente os arquivos de demonstraçêo; registre a alteraçêo. Em Settings → Pages, escolha a origem por branch e a pasta raiz, quando essa opçêo estiver disponível. Aguarde o endereço informado pela plataforma e faça os testes. A disponibilidade depende da conta e da configuraçêo; se a tela diferir, consulte a ajuda oficial do GitHub Pages. Nunca envie credenciais. Nêo há necessidade de contratar serviços de IA por API para hospedar esta demonstraçêo.
