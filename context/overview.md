# Visêo geral

Curso v6 em português para aprender a desenvolver com IA. 24 aulas em 6 módulos; organizador pessoal de demandas como exemplo. Fonte: entrevista fornecida pelo usuário; desenvolvimento autoral.

A aplicaçêo usa somente armazenamento do navegador. As aulas sobre permissões sêo exercícios de análise para uma versêo futura, sem apresentar a aplicaçêo pessoal como sistema multiusuário.
