Para quem é

É para você se

  • É professor ou prestador de serviço e quer organizar uma tarefa recorrente.
  • Tem pouco tempo e nenhuma base técnica.
  • Prefere aprender fazendo.

Nêo é para você se

  • Busca formaçêo avançada em engenharia ou certificaçêo de segurança.
  • Precisa de um sistema multiusuário pronto para produçêo.
